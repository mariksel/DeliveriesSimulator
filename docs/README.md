# DeliveriesSimulator Documentation

A Markdown documentation system with two parts that link to each other:

- [Design](design/README.md) — the versioned design and architecture record. It
  is authoritative for product rules, architecture, and decisions.
- [Backlog](backlogs/development-backlog.md) — the record of past, present, and
  planned work. It is authoritative for work lifecycle status.

It works without tooling. The rules are written in the
[backlog system guide](backlogs/system/backlog-system-guide.md) and
[document governance](design/governance/document-governance.md).

Agent instructions for this project are in [CLAUDE.md](../CLAUDE.md).
